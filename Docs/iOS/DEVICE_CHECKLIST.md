# 云端 macOS 和 iPhone 验证清单

这些步骤不能用 Windows 脚本编译结果替代。macOS 可以是现有 GitHub Actions runner，安装验证沿用已有的手机签名流程。

## macOS 构建

- [ ] 固定 Unity 6000.0.24f1、iOS 模块与实际 Xcode 版本；在日志中记录所有版本。
- [ ] 原生 arm64 archive 成功；`nm` 核对内核、服务器、SQLite 和 ABI 检查入口，无重复 ocgcore / Lua / SQLite 实现。
- [ ] iOS 平台脚本编译、IL2CPP 与 Xcode 最终链接成功，无缺失反向 P/Invoke、动态库或泛型 AOT 代码。
- [ ] SQLite 的旧托管 DLL 在 iOS 排除；三个卡库加载器确实走 callback-free provider。
- [ ] Addressables 的所有 GUID 和默认场景依赖齐全；Spine 固定版本与上游包内骨骼资源兼容。
- [ ] `prepare_resources.py` / `verify_resources.py` 通过；StreamingAssets 无全量卡图、全套外观及旧资源压缩包。
- [ ] `.app` 文件总长不超过 450 MB，保存 storage JSON；IPA 无签名打包成功。此处只能证明文件总长，尚不等于 iOS 设置显示的磁盘占用。

## iPhone 启动和卡图

- [ ] 首次启动、第二次启动、覆盖安装；中文字体、搜索、卡组编辑和安全区可用。
- [ ] 无卡图能显示卡片文字、占位图和完整操作控件；卡图缺失不能阻塞交互。
- [ ] 先后打开普通卡、灵摆卡、连接卡、先行卡；验证下载域名、中文卡图裁切及实时刷新。
- [ ] 断网、404、慢网、杀进程、切后台再返回；`.part` 清理、失败重试、重复请求合并和恢复正常。
- [ ] 超过缓存配额后淘汰旧图；重启保留最近卡组的主/额外/副卡组；清缓存不删卡组和回放。
- [ ] 核对各外观设置：未打包的场地/特效不应被重新启用后造成空场或异常；必要时继续隐藏不可用选项。

## Bot、联机和先行卡

- [ ] 在线预取卡组后开飞行模式，至少两套 Bot 从准备到结束完整对局，含换边、效果链、复盘。
- [ ] 切换 Bot、连续重开十局、退出返回、后台挂起；无残留线程、端口占用或不断增加的内存。
- [ ] MyCard 登录、匹配、准备、完整对局、Side、重连；记录客户端/服务器实际协议版本。不要把账号令牌写进公开日志。
- [ ] 先行卡更新成功后重启，数据库与 Lua 生效；最终 YPK 无 `pics`；先行卡图首次出现才下载。
- [ ] 更新中断、超配额、无效 ZIP；旧先行卡包和版本状态保留。验证官方格式变化时能明确报错。
- [ ] 回放的 YRP / YRP2、手牌测试和本地决斗核对新版内核 `rule_code` 及消息格式；仅改协议号不代表消息兼容。

## 总占用验收

- [ ] 记录 iOS 设置的“App 大小 + 文稿与数据”，覆盖首次安装、首次复制数据、缓存充满、先行卡更新峰值。
- [ ] 连续使用、生成回放、导入允许大小的扩展包后仍低于 1,000,000,000 字节。
- [ ] 缓存缩容时固定资源无法容纳有清楚提示；不会自动删除用户数据。
- [ ] 用实测余量调整缓存上限或基础资源；超限时构建或下载失败，不能仅比较压缩 IPA 大小。
